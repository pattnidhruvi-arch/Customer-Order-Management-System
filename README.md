# Customer Order Management System✨

## 1. Introduction
The Customer Order Management System is a database project developed using MySQL and phpMyAdmin. It helps organize and manage customer, employee, and order information in a structured way.

## 2. Project Objectives
- To store customer information.
- To manage employee details.
- To maintain order records.
- To retrieve information using SQL queries.
- To perform database operations efficiently.
- To understand database management concepts.

## 3. Tools and Technologies
- **Database:** MySQL
- **Database Management Tool:** phpMyAdmin
- **Documentation:** Microsoft Word
- **Language:** SQL

## 4. Database Information
- **Database Name:** `datatransformer`
- **Tables:** `customers`, `employees`, `orders`

## 5. Project Modules

### Customers
Stores and manages customer-related information.

### Employees
Stores employee details such as names, departments, hire dates, and salaries.

### Orders
Maintains order-related records for the system.

## 6. SQL Operations
The project uses SQL operations such as:
- `CREATE` – creates database tables.
- `INSERT` – adds records.
- `SELECT` – retrieves records.
- `UPDATE` – modifies existing records.
- `DELETE` – removes selected records.
- `WHERE` – filters records based on conditions.
- `JOIN` – combines related data from multiple tables, when applicable.

## 7. Project Files
- `SQL PROJECT REPORT 3.docx` – project documentation.
- `customers.sql` – customer-related SQL queries.
- `employees.sql` – employee-related SQL queries.
- `orders (1).sql` – order-related SQL queries.
- `datatransformer.sql` – database SQL file.

## 8. Expected Outcome
This project demonstrates how SQL can be used to organize, retrieve, and manage customer, employee, and order data.

## 9. Conclusion
The Customer Order Management System provides practical experience in database creation, table management, and SQL queries. It helps develop a basic understanding of relational database management using MySQL and phpMyAdmin.
